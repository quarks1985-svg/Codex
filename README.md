# 🎸 Vibe Agent — бесплатный ИИ-агент для вайбкодинга

Описываешь задачу словами — агент сам пишет код, создаёт и правит файлы,
запускает команды, проверяет результат и чинит ошибки. Полностью бесплатно.

## Быстрый старт (бесплатно, без ключей)

1. Установите [Ollama](https://ollama.com) и скачайте кодинг-модель:
   ```bash
   ollama pull qwen2.5-coder:7b     # ~4.7 ГБ, хорошо пишет код
   # или, если мало RAM: ollama pull qwen2.5-coder:3b / phi4-mini
   ```
2. Запустите агента в папке проекта:
   ```bash
   python3 vibe_agent.py "сделай cli-заметки с сохранением в json"
   python3 vibe_agent.py            # интерактивный режим (REPL)
   ```

## Альтернатива: бесплатные модели через OpenRouter

```bash
export OPENROUTER_API_KEY=sk-or-...   # бесплатный ключ на https://openrouter.ai
python3 vibe_agent.py --provider openrouter \
    --model deepseek/deepseek-chat-v3-0324:free "напиши игру змейка на pygame"
```

Также поддерживается любой OpenAI-совместимый API (`--provider openai`,
переменные `OPENAI_API_KEY` / `OPENAI_BASE_URL`).

Бэкенд выбирается автоматически: Ollama → OpenRouter → OpenAI.

## Что умеет агент

| Инструмент    | Действие                                        |
|---------------|-------------------------------------------------|
| `read_file`   | читать файлы                                    |
| `write_file`  | создавать/перезаписывать файлы                  |
| `edit_file`   | точечно заменять фрагменты кода                 |
| `list_dir`    | смотреть содержимое папок                       |
| `run_command` | выполнять shell-команды (запуск и тесты кода)   |
| `done`        | завершить задачу с итогом                       |

Цикл: задача → план → написал файл → запустил → увидел ошибку → исправил → повтор,
пока не заработает (автономно, до `--max-steps` шагов).

## Настройки

| Переменная / флаг      | Значение по умолчанию                     |
|------------------------|-------------------------------------------|
| `--provider`           | автовыбор                                 |
| `--model`              | `qwen2.5-coder:7b` (Ollama) / `...:free` (OpenRouter) |
| `OLLAMA_HOST`          | `http://localhost:11434`                  |
| `VIBE_MAX_STEPS`       | 30                                        |
| `VIBE_CMD_TIMEOUT`     | 60 сек                                    |

## Безопасность

- Все пути ограничены рабочей директорией (выход наружу запрещён).
- Опасные команды (`rm -rf /`, `mkfs`, …) отклоняются.
- Запускайте в папке проекта или песочнице.

Зависимости: Python 3.9+; пакет `openai` нужен только для облачных бэкендов
(`pip install openai`), локальный Ollama работает на стандартной библиотеке.
