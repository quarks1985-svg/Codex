# Как скачать главную страницу (index.html)

## Способ 1 — прямая ссылка (если платформа отдаёт файлы)
- **index.html** (рабочая страница, 56 КБ): https://chinalaser.spb.ru/../_sandbox/index.html ❌
  В песочнице используйте локальный сервер: откройте в браузере
  `http://localhost:8099/index.html` → «Сохранить как» (Ctrl+S).
- **preview.pdf** (предпросмотр десктоп + мобайл картинками): `http://localhost:8099/preview.pdf`
- **preview_desktop.png** (вся страница целиком): `http://localhost:8099/preview_desktop.png`
- **preview_mobile.png** (мобильная версия): `http://localhost:8099/preview_mobile.png`

## Способ 2 — через git
Файлы закоммичены (коммиты `6000eec`, `87bcebe`). Если у вас есть доступ
к репозиторию песочницы:
```bash
git pull && cp index.html ~/sites/chinalaser/
```

## Способ 3 — base64 (гарантированный, без доступа к файлам)
1. Откройте **index_b64_pages.pdf** или **index_download.svg** — там код страницы
   base64 построчно (только для preview.html; полный index.html — в `index.html.b64`).
2. Скопируйте все строки в один файл `b64.txt` (без пробелов и переносов внутри строк кода).
3. Декодируйте:
   - macOS / Linux: `base64 -d b64.txt > index.html`
   - Windows (PowerShell): `[IO.File]::WriteAllBytes("index.html",[Convert]::FromBase64String((gc b64.txt) -join ""))`

## Что где лежит
| Файл | Назначение |
|---|---|
| `index.html` | Главная страница со всеми исправлениями аудита — публиковать её |
| `preview.html` | Упрощённая версия для скриншотов (без JS/карт) |
| `preview_desktop.png` | Скриншот всей страницы на десктопе (1240px) |
| `preview_mobile.png` | Скриншот первого экрана на мобильном (390px) |
| `preview.pdf` | Оба скриншота в одном PDF |
| `index.html.b64` | Base64 полной страницы |
| `index_download.svg` / `index_b64_pages.pdf` | Base64 для ручного копирования |

⚠️ Перед публикацией замените плейсхолдеры: ИНН/ОГРН, телефон, e-mail,
ID Яндекс.Метрики, URL CRM, реальные фото и видео.
